# Security Policy

## Supported Versions

The supported version for coordinated vulnerability reporting is:

| Version | Supported |
|---------|-----------|
| `main` | yes |

## How to Report

If you believe you found a security issue in this repository, report it privately to the maintainer instead of opening a public issue with exploit details.

Include, if possible:

- affected commit or branch
- clear reproduction steps
- impacted component or scenario
- expected versus observed behavior
- any logs, packet captures, or screenshots needed to reproduce the issue

## Response Expectation

This repository is maintained as part of an academic project, so response times are best-effort rather than SLA-backed.

The intended handling model is:

- initial acknowledgement within 7 days when the report is actionable
- follow-up after triage when reproduction is confirmed or when more detail is needed
- remediation timing depends on academic workload, scope of the issue, and whether the finding affects ongoing thesis evaluation artifacts

## Academic Testbed Note

This repository is an academic laboratory testbed for IoT security experiments. It is not a production system, not a managed service, and not intended for deployment as-is in operational environments.

Please report vulnerabilities responsibly and avoid testing against third-party systems or infrastructure you do not own or explicitly control.
